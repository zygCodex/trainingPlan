# 练就 · 四分化训练

Vue 3 + Vite 的移动端训练 Demo，纯静态部署，无后端、无外部字体或图片依赖。

## 本地开发

需要 Node.js 22 或更高版本。

```sh
npm ci
npm run dev
```

```sh
npm run build
npm run preview
```

构建输出在 `dist/`。不要直接双击源码 `index.html`，使用开发服务器或部署构建产物。

## 功能

- 今日训练：手动选择胸、背、腿、肩或主动恢复；热身和正式训练按原文顺序展示。
- 展开要领、器械、作用区域、来源和个人心得；当天替换动作，可恢复原动作。
- 每项打勾代表所有组数完成，包含热身；全部完成后庆祝，同一天同一训练日只自动庆祝一次。
- 已完成动作替换时确认并取消该项完成状态；哥本哈根支撑剂量未明确，暂不允许直接替换。
- 全部数据：完整计划、7个热身动作、25个正式动作（含可选形式）；动作库支持名称、器械和肌肉区域搜索。
- 掌握程度：热身与正式动作库均支持 1–10 分自评，显示五档熟练度文案，支持修改或清除评分。按动作 ID 长期保存在当前浏览器，不随训练日或日期重置。
- 个人心得暂为只读，数据来自整理文档。

## 数据与目录

`training-plan.md` 是内容依据。编辑后执行 `npm run data:sync`，更新 `src/data/training.json`，一并提交。

- `src/components/`：训练日选择、训练列表、动作详情、资料库、完成弹窗。
- `src/composables/useTraining.js`：本地日期、训练选择、完成记录、替换与持久化。
- `src/composables/useMastery.js`：动作掌握程度、熟练度文案与独立本地存储（`lianjiu.mastery.v1`）。
- `src/data/`：动作数据与训练日展示文案。

记录使用 `localStorage`，按设备本地日期和训练日保存，跨日重置今日选择但不删除历史数据；刷新恢复，不支持跨设备同步。清理浏览器数据会删除记录。浏览器禁止保存时会显示提示并允许继续使用。

## GitHub Pages

已提供 `.github/workflows/pages.yml`。在仓库 **Settings → Pages → Build and deployment → Source** 中选择 **GitHub Actions**，随后推送到 `main` 或手动运行该工作流。

部署成功后，项目页面通常为 `https://zygCodex.github.io/trainingPlan/`（以工作流实际输出为准）。Vite 使用相对资源路径，可用于项目子目录部署。无需后端服务。
